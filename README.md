# MAX Bot с локальной LLM через Ollama

Бот для мессенджера MAX, который отвечает на сообщения с помощью локальной языковой модели. Работает полностью на вашем компьютере — без затрат на API и без отправки данных третьим лицам.

## ✨ Возможности

- Отвечает на текстовые сообщения через локальную модель `qwen2.5:latest`
- Работает без интернета (кроме самого мессенджера MAX)
- Токен бота хранится в `.env` и не попадает в репозиторий
- Логи пишутся в `max_bot.log` и в консоль

## 🛠️ Стек

- **Python 3.10+**
- [**maxapi**](https://pypi.org/project/maxapi/) — библиотека для работы с MAX Bot API
- [**Ollama**](https://ollama.com/) — локальный сервер LLM
- **aiohttp** — асинхронные HTTP-запросы к Ollama
- **python-dotenv** — загрузка токена из `.env`
## 🧪 Выбор модели: trade-off скорости и качества

В проекте протестированы три модели Ollama:

| Модель | Скорость | Качество (рус.) | Процессор |
|---|---|---|---|
| `llama3.2:3b` | ⚡ 1–3 сек | ⭐⭐ | 100% GPU |
| `qwen2.5:3b` | ⚡ 2–5 сек | ⭐⭐⭐⭐ | 100% GPU |
| `qwen2.5:7b` | 🐢 15–30 сек | ⭐⭐⭐⭐⭐ | 52%/48% CPU/GPU |

**Текущий выбор:** `qwen2.5:latest` — приоритет качества ответов.

**Причина:** для задач, где важна точность и качество русского языка, 7B-модель заметно превосходит 3B-варианты. Плата — скорость ответа, поскольку модель не полностью помещается в VRAM и работает в гибридном режиме CPU+GPU.

**В планах:** переключение модели по команде — `/fast` для быстрых ответов (`qwen2.5:3b`), `/deep` для сложных вопросов (`qwen2.5:7b`). Это даст пользователю выбор между скоростью и качеством.
